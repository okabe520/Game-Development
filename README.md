# 异世界RPG

2D 俯视角回合制 RPG 游戏，基于 Unity 开发。

## 玩法

- **地图探索**：方向键移动，接触怪物触发点进入战斗
- **回合制战斗**：速度决定出手顺序，可选择攻击/技能/道具/防御
- **技能系统**：6 个技能随等级解锁，消耗法力或怒气
- **Boss 战**：5 种独特 Boss，各有专属机制

## Boss 一览

| Boss | 机制 |
|------|------|
| 拦路骷髅兵 | 高血量，20% 减伤 |
| 狂暴龙王 | 攻击力每回合递增，30% 血触发死吼狂暴 |
| 影武者 | 30% 概率一回合攻击两次 |
| 石先锋 | 高防御，概率反击；低血触发石之意志吸收反击 |
| 嗜血狼人 | 两条命，每 6 回合回血，终极技死亡契约 |

## 技能

| 技能 | 消耗 | 效果 |
|------|------|------|
| 火球术 | MP | 单体火焰伤害 + 灼烧 |
| 冰锥 | MP | 单体冰伤害 + 冻结 |
| 雷击 | MP | 单体雷伤害 + 感电 |
| 虚弱 | MP | 降低敌人攻击力 |
| 治疗术 | MP | 回复生命值 |
| 灵魂激流 | 怒气 | 终极技，消耗全部怒气 |

## 存档

JSON 序列化，3 个存档位，支持新游戏/继续/手动读档，击败 Boss 后自动存档。

## 运行

1. 用 Unity 2022.3+ 打开项目
2. 进入 `Assets/Scenes/MainMenu` 场景
3. 点击 Play

## 项目结构

```
Assets/
├── Bosses/          # Boss 脚本
├── Scripts/         # 战斗/存档/UI 脚本
├── Scenes/          # 场景文件
├── Animations/      # 动画资源
├── Art/             # 美术资源
├── Audio/           # 音频资源
└── Prefabs/         # 预制体
```
